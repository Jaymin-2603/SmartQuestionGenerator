# Smart Question Paper Generator

An AI-powered system for automatically generating university question papers based on subject, topics, marks, duration and difficulty requirements.

## Technology Stack

- React
- Vite
- FastAPI
- Python
- Ollama
- Gemma 3 4B
- ReportLab
- PyPDF
- Pandas

## Project Structure

- `frontend/` — React + Vite single-page application (JavaScript, Axios for API calls).
- `backend/` — FastAPI application exposing the REST API under `/api`, prepared for future Ollama integration.
- `data/input/` — Source material for question generation (syllabus PDFs, question banks, CSVs) — added in a later phase.
- `data/output/` — Generated question papers — added in a later phase.
- `docs/` — Project documentation.
